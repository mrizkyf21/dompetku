    Foto struk dibaca oleh Google Gemini (gratis) untuk mengisi transaksi secara otomatis. Butuh internet dan API key Gemini milik Anda.

    Cara mendapatkan API key gratis
    1. Buka aistudio.google.com/apikey dan login dengan akun Google.
    2. Ketuk Create API key, lalu salin key-nya.
    3. Tempel di kolom di atas, ketuk Simpan, lalu Tes koneksi.

    Pada paket gratis, Google dapat memakai foto struk untuk meningkatkan layanannya. API key hanya disimpan di HP ini dan tidak ikut dalam file cadangan.
